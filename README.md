# WhyChess

Расширение для Firefox, которое помогает начинающим шахматистам разбирать свои партии. После
окончания партии WhyChess показывает лучший ход в каждой позиции и подробно объясняет на русском
языке, почему движок считает его лучшим.

Расширение работает с **Chess.com** и **Lichess**, а если автоматически найти партию не удалось,
текст PGN можно вставить вручную. Весь расчёт выполняется локально: встроенный Stockfish не
отправляет партию на серверы.

## Возможности

- Лучший ход для каждой позиции партии, а не только для текущей.
- Понятное объяснение без сленга: что делает ход, что он защищает, на что нападает, как меняется
  оценка позиции.
- Сравнение сыгранного хода с рекомендацией движка: «лучший ход», «отличный ход», «хороший ход»,
  «неточность», «ошибка», «грубая ошибка», «вынужденный ход».
- Оценка потери в пешках, вариант продолжения и возможный ответ соперника.
- Схема позиции прямо в карточке хода: золотая стрелка — лучший ход, красная — сыгранный.
- Клик по карточке хода переключает доску сайта на этот же ход.
- Опциональные стрелки на самой доске Chess.com или Lichess.
- Фильтры «Все ходы», «Мои ходы» и «Ошибки».
- Сводка после разбора: количество ошибок, средняя потеря, распределение оценок.
- Ручной разбор PGN.
- Настройки глубины, лимита полуходов, автоматического открытия и стрелок.

## Установка

Для работы нужен Firefox 140 или новее.

```powershell
npm install
npm run build
```

После сборки появится каталог `extension/`. Загрузите его как временное дополнение:

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение…»**.
3. Выберите файл `extension/manifest.json`.
4. Откройте завершённую партию на Chess.com или Lichess.

Временное дополнение живёт до перезапуска Firefox. Для постоянной установки расширение нужно
подписать в Mozilla Add-ons (AMO) или установить в Firefox Developer Edition / Nightly с отключённой
проверкой подписи.

## Как пользоваться

1. Откройте страницу завершённой партии или страницу анализа на Chess.com либо Lichess.
2. WhyChess сам найдёт партию и, если включено автоматическое открытие, запустит разбор.
3. Если панель не появилась, нажмите круглую кнопку с конём в правом нижнем углу страницы.
4. Дождитесь окончания расчёта. Ходы появляются постепенно, по мере готовности.
5. Раскройте карточку хода. В ней будут:
   - лучший ход и его оценка;
   - потеря относительно лучшего хода;
   - вариант движка;
   - возможный ответ соперника;
   - объяснение на русском языке;
   - схема позиции перед ходом.
   При раскрытии карточки доска на сайте переключается на этот же ход.
   Схема в карточке всегда повёрнута в вашу сторону, поэтому ходы соперника читаются с той же
   точки зрения, а их подсказки и стрелки остаются на месте. Если сторона неизвестна (например,
   при ручном разборе PGN), схема разворачивается в сторону сделавшего ход.
6. Кнопка **«Показать на доске»** возвращает доску к позиции перед ходом и рисует
   стрелки лучшего и сыгранного хода. Если сайт не даёт это сделать, схема в карточке всё равно
   доступна.

Фильтр **«Мои ходы»** определяет вашу сторону по аккаунту, под которым вы вошли на сайт.
На странице анализа Lichess сторона берётся из ссылки вида `/analysis/<партия>/<цвет>`, по
которой вы открыли разбор. Если сайт не показывает, кто играет, фильтр скрывается, чтобы не
выдавать ходы соперника за ваши.

### Положение и размер панели

Панель можно перетащить за заголовок и увеличить или уменьшить, потянув за правый нижний
угол. Когда ручка изменения размера в фокусе, размер меняется стрелками клавиатуры
(`Shift` — крупный шаг). Положение и размер сохраняются в профиле Firefox. Ссылка
**«Сбросить окно»** в нижней части панели возвращает исходное место в правом верхнем углу.

### Оформление панели

Панель автоматически подстраивается под сайт: определяет светлую или тёмную тему страницы и
переключается вместе с ней. На Lichess и Chess.com используются фирменные зелёные акценты и цвета
доски этих сайтов; на других страницах остаётся золотистое оформление. Цвета заголовка, кнопок,
вкладок, прогресса, фильтров и схемы позиции меняются согласованно, а текст остаётся читаемым в
обеих темах. Оформление намеренно строгое: плоские поверхности, тонкие границы, небольшие радиусы
и без декоративных градиентов — акцент остаётся на разборе ходов и схеме позиции.

### Ручной разбор PGN

Откройте вкладку **«Вставить PGN»** в панели, вставьте текст одной партии и нажмите
**«Разобрать PGN»**. Заголовки не обязательны: достаточно списка ходов, например:

```text
1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 4. Ba4 Nf6 5. O-O Be7
```

Поддерживаются только обычные шахматы. Для вариантов (Chess960, Crazyhouse и других) расширение
покажет сообщение о том, что вариант не поддерживается.

## Как это работает

- Контент-скрипт извлекает партию со страницы: список ходов, PGN, имена игроков и ориентацию доски.
- Фоновая страница расширения держит один экземпляр Stockfish 10 (asm.js) в Worker.
- Разбор идёт по позициям: начальная позиция плюс позиция после каждого хода. Для партии из `N`
  полуходов выполняется `N + 1` поиск.
- Для каждого хода сравнивается оценка лучшего продолжения с оценкой позиции после сыгранного хода.
  Разница в сантипешках переводится в категорию:

| Потеря относительно лучшего хода | Категория |
| --- | --- |
| ход совпал с лучшим | лучший ход |
| до 25 сантипешек | отличный ход |
| до 60 | хороший ход |
| до 120 | неточность |
| до 300 | ошибка |
| больше 300 | грубая ошибка |
| единственный законный ход | вынужденный ход |

- Объяснение собирается детерминированно из особенностей позиции: взятие, шах, мат, рокировка,
  превращение, развитие, контроль центра, защита фигуры, двойное нападение и так далее. Это не
  генеративный текст и не обращение к языковой модели.
- Оценка всегда показывается с точки зрения белых. Движок считает в сантипешках: `+0,35` означает
  преимущество белых примерно в треть пешки.

### Глубина и время

По умолчанию используется глубина 10 и лимит 80 полуходов. Для партии из 80 полуходов это 81
позиция, поэтому разбор может занять несколько минут. Увеличивать глубину стоит на мощном
компьютере; на слабом ноутбуке лучше выбрать 8. Лимит полуходов можно поднять до 300 или поставить
0, чтобы разбирать партию целиком.

## Приватность

- Партия и результаты расчёта не покидают компьютер.
- Расширение не содержит аналитики, телеметрии и внешних запросов.
- Разрешение `storage` нужно только для сохранения настроек и положения панели в профиле Firefox.
- Контент-скрипт работает на страницах Chess.com и Lichess, чтобы прочитать ходы партии и показать
  панель. Другие сайты не затрагиваются.

## Ограничения

- Только стандартные шахматы.
- Автоматическое открытие не срабатывает для партий, которые ещё идут, и для страниц живых партий
  Chess.com (`/play/`, `/game/live/`). Такие партии можно разобрать вручную, если список ходов уже
  доступен, либо после окончания партии.
- Стрелки на доске зависят от разметки сайта и могут не сработать после обновления Chess.com или
  Lichess. Схема в карточке хода от этого не зависит.
- Stockfish 10 — не самая новая версия движка. Она выбрана за стабильную работу в виде обычного
  asm.js-воркера без WebAssembly, cross-origin isolation и дополнительных разрешений.
- Оценка на глубине 10 приблизительная. Для серьёзного анализа увеличивайте глубину и проверяйте
  ключевые позиции отдельно.

## Разработка

```powershell
npm install
npm test          # тесты Vitest
npm run build     # сборка extension/
npm run watch     # пересборка при изменении исходников
npm run check     # тесты и сборка
```

### Структура проекта

```text
src/
  background.js          фоновая страница, порт и управление заданиями
  background/
    analyzer.js          разбор позиций и события прогресса
    uci-engine.js        UCI-клиент для Stockfish
  content/
    content.js           связывает страницу, панель и фоновую часть
    extract.js           извлечение партии с Chess.com и Lichess
    panel.js             Shadow DOM панель и карточки ходов
    panel-geometry.js    перемещение и изменение размера панели
    theme.js             определение светлой/тёмной темы сайта
    panel.css            стили панели и кнопки запуска
    board.js             FEN-схема, мини-доска и SVG-стрелки
    board-overlay.js     стрелки поверх доски сайта
  options/               страница настроек
  shared/
    analysis.js          классификация ходов и отчёты
    chess-utils.js       PGN, SAN, оценки и терминальные позиции
    explain.js           текстовые объяснения на русском
    features.js          признаки позиции и хода
    settings.js          хранение настроек
    constants.js         общие константы
  manifest.json
vendor/
  stockfish.asm.js       движок Stockfish 10
scripts/
  build.js               сборка расширения
  icons.js               генерация PNG-иконок
tests/                   тесты
```

Тесты не запускают настоящий Stockfish: UCI-клиент проверяется на поддельном Worker, а пайплайн
разбора — на поддельном движке с заданными оценками.
